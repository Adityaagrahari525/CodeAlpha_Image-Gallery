# CodeAlpha Image Gallery

A lightweight, responsive image gallery built with plain HTML, CSS, and JavaScript. It allows users to add images from their device, view them in a lightbox, navigate between images, and remove any image from the collection.

## Features

- Responsive gallery layout
- Add multiple images from local files
- Full-size lightbox viewer
- Previous/next image navigation
- Image removal from the gallery
- Live image count updates
- Clean, modern UI

## Project Structure

- `index.html` – main page structure
- `style.css` – gallery styling and layout
- `script.js` – image handling, gallery logic, and lightbox behavior
- `images/` – default demo images shipped with the project

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Adityaagrahari525/CodeAlpha_Image-Gallery.git
   ```
2. Open the project folder:
   ```bash
   cd CodeAlpha_Image-Gallery
   ```
3. Start a local server or open `index.html` directly in a browser.

### Option 1: Open directly
Open `index.html` in your browser.

### Option 2: Use a local server
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Usage

- Click the `Add images` button to select image files from your device.
- Click any gallery item to open it in the lightbox viewer.
- Use the arrow buttons or keyboard navigation to move between images.
- Use the delete button on a card to remove an image from the gallery.
